# Android 复古游戏大厅需求说明书

## 1. 产品定位

本产品是一个自用型 Android 复古游戏大厅，第一版聚焦 FC / NES 红白机游戏。

产品形态不是专业模拟器，而是“打开即进入游戏库，选中进入详情页，再开始游玩”的横屏游戏大厅。它把游戏浏览、详情确认、启动、输入、存档和基础设置整合到一个 APK 内，让普通用户可以开箱即用，让有定制化需求的玩家可以主动进入设置页调整体验。

第一版仅供个人研究和本地验证，不面向公开分发。

## 2. 目标设备

第一版支持：

- Android 手机
- Android TV
- Android 电视盒子

设备要求：

- 同一个 APK 尽量同时兼容手机和电视。
- 第一版统一横屏使用。
- 电视按“大屏横屏设备”处理。
- 手机也必须支持手柄完整操作。
- 焦点、手柄、遥控器操作是基础能力，触摸是补充能力。

## 3. 第一版范围

第一版必须支持：

- 打开 App 直接进入游戏大厅。
- 内置游戏库，用户打开即可选择游戏。
- 游戏以封面和名称网格展示。
- 支持分类。
- 支持搜索。
- 支持收藏。
- 支持最近游玩。
- 从游戏库、最近游玩、搜索和收藏中选中游戏后进入游戏详情页。
- 游戏详情页提供开始游戏入口，再由详情页启动游戏。
- 使用 libretro 方案集成成熟 FC / NES 模拟核心。
- 支持 `.nes`。
- 支持 SRAM 自动存档。
- 支持 1 个自动即时存档槽。
- 支持 3 个手动即时存档槽。
- 支持即时存档和读档。
- 支持自动保存。
- 支持重置游戏。
- 支持暂停和继续。
- 支持退出游戏返回大厅。
- 支持画面比例设置。
- 支持基础滤镜或像素原始显示。
- 支持声音开关和音量设置。
- 支持手机虚拟按键。
- 支持手机手柄。
- 支持电视遥控器。
- 支持电视手柄。
- 支持焦点导航。
- 支持普通用户不配置即可游玩。
- 支持定制玩家主动进入设置页调整体验。

第一版明确不支持：

- 不支持用户手动导入本地 ROM。
- 不支持添加游戏源。
- 不支持浏览游戏源。
- 不支持从游戏源下载 ROM。
- 不支持账号。
- 不支持云同步。
- 不默认提供商业 ROM 源。
- 不做多机种模拟。
- 不做在线多人。
- 不做复杂金手指、调试器等专业模拟器功能。
- 不面向公开分发带 ROM 的 APK。

## 4. 游戏来源

第一版游戏库来自 App 内置游戏。这里的“内置游戏库”指 App 启动后不向用户暴露导入入口、不要求用户在 UI 中选择 ROM 文件；但公开仓库不提交 ROM，公开构建也不发布带 ROM 的 APK。

内置游戏数据来源：

- 开源社区仓库 `tomiaa12/nesRoms`
- 使用范围限定为个人研究和本地验证
- 不面向公开分发
- 不发布带 ROM 的 APK

ROM 数据、本地私有资源、个人测试资源应放在 git 外部或私有环境中。

第一版本地验证采用“私有资源注入”机制：

- 公开 git 仓库只保存游戏索引结构、占位封面、资源复制逻辑和文档。
- 本机私有目录保存 `.nes`、libretro core、真实封面等资源。
- Debug / private build 可在构建期把私有资源复制到构建产物的 assets 中，或在安装后由开发脚本推送到 App 私有目录。
- App 首次启动时从 assets 或 App 私有目录初始化游戏索引、ROM、封面和 core。
- UI 不提供本地 ROM 导入入口，这与开发期私有资源注入不冲突。
- 最终验收必须至少有一个通过私有资源注入准备好的 NES 游戏能用真实 libretro core 启动。

## 5. 游戏大厅 UI

大厅采用统一横屏大屏布局：

```text
左侧：分类
右侧：游戏封面网格
顶部：搜索 / 设置
底部：操作提示
```

底部操作提示示例：

```text
A 详情    B 返回    菜单 设置
```

UI 风格：

- Switch / Steam Deck 结合现代风。
- 大封面、清晰焦点、横向或网格浏览。
- 视觉简洁，但有游戏机大厅感。
- 大屏可读。
- 不做普通移动 App 风格。
- 不做过度复古像素风。

大厅交互要求：

- 焦点高亮明显。
- 遥控器和手柄上下左右移动顺畅。
- 手机可触摸点击。
- 手机可用手柄完整操作。
- 搜索、分类、收藏、最近游玩都支持焦点操作。
- 游戏库、最近游玩、搜索和收藏中的游戏卡片使用一致交互：确认或触摸点击进入游戏详情页。

游戏详情页要求：

- 显示游戏封面、标题、平台、分类、收藏状态和最近游玩信息。
- 提供开始游戏入口。
- 提供收藏切换入口。
- 支持焦点、遥控器、手柄和触摸操作。
- Back 返回进入详情页前的列表位置。

## 6. 游戏内体验

手机游戏内：

- 横屏全屏。
- 默认显示虚拟方向键。
- 默认显示 A / B / Start / Select。
- 支持触摸菜单按钮打开暂停菜单。
- 连接手柄时可以隐藏虚拟按键。
- 支持虚拟按键透明度调整。
- 支持虚拟按键大小调整。
- 支持虚拟按键位置调整。

电视游戏内：

- 横屏全屏。
- 默认不显示虚拟按键。
- 完全通过手柄或遥控器操作。
- 菜单键或组合键打开暂停菜单。
- 暂停菜单支持保存、读档、退出和设置。

暂停菜单包含：

- 继续游戏
- 保存即时存档
- 读取即时存档
- 重置游戏
- 画面设置
- 声音设置
- 退出到大厅

即时存档槽位：

- 自动槽：1 个
- 手动槽：3 个

## 7. 输入系统

系统内部统一抽象为一套输入动作：

```text
上 / 下 / 左 / 右
确认 / 返回 / 菜单
FC A / FC B
Start / Select
```

手机触摸：

- 点击游戏
- 点击菜单
- 使用虚拟方向键
- 使用虚拟 A / B / Start / Select

手机手柄：

- 方向键映射到上 / 下 / 左 / 右
- A / B 映射到 FC A / FC B
- Start / Select 映射到 FC Start / Select
- Back / Menu 映射到返回 / 菜单

电视遥控器：

- 方向键映射到上 / 下 / 左 / 右
- OK 映射到确认
- Back 映射到返回
- Menu 映射到菜单

电视手柄：

- 方向键映射到上 / 下 / 左 / 右
- A / B 映射到 FC A / FC B
- Start / Select 映射到 FC Start / Select
- Back / Menu 映射到返回 / 菜单

## 8. 本地游戏库

本地游戏库保存可通过详情页启动的游戏。

游戏信息包括：

- 游戏 ID
- 游戏标题
- 平台
- 分类
- 封面路径
- ROM 本地路径
- 收藏状态
- 最近游玩时间
- 累计游玩时长
- SRAM 存档路径
- 即时存档路径

本地数据要求：

- 结构化数据使用 Room。
- 用户设置使用 DataStore。
- 封面缓存使用 Coil。
- ROM、SRAM、即时存档放在 App 私有目录。

## 9. 模拟器能力

第一版只支持 FC / NES。

模拟器能力：

- 使用 libretro 方案集成成熟 FC / NES 模拟核心。
- App 内置模拟核心，不要求用户下载核心。
- 加载 `.nes`。
- 启动、暂停、继续、重置、退出。
- 视频帧渲染。
- 音频输出。
- 输入注入。
- SRAM 自动保存。
- 即时存档保存和读取。
- 画面比例控制。
- 基础滤镜或原始像素显示。

## 10. 设置

设置采用“双层体验”原则：

- 普通用户使用默认配置即可正常游玩。
- 有定制需求的玩家可以主动进入设置页调整体验。
- 基础设置优先展示，调整后立即生效。
- 高级设置收纳在更深一级，不干扰普通用户。

基础设置：

- 画面比例
- 滤镜开关
- 声音开关
- 音量
- 虚拟按键显示方式
- 虚拟按键透明度
- 虚拟按键大小
- 虚拟按键位置
- 清理缓存

高级设置：

- 单个游戏的画面比例覆盖
- 单个游戏的滤镜覆盖
- 单个游戏的声音开关覆盖
- 手柄连接时是否自动隐藏虚拟按键
- 自动即时存档策略

## 11. 技术栈

第一版技术栈：

- Kotlin
- Jetpack Compose
- Android NDK
- libretro
- 成熟 FC / NES libretro core
- Room
- DataStore
- Coil

第一版采用单 module 工程结构，通过 package 分层维护边界。

## 12. 版权和发布边界

项目目标是个人研究和技术验证，不面向公开分发。

约束：

- 不把商业 ROM 放进公开仓库。
- 不公开发布带 ROM 的 APK。
- 不默认内置商业 ROM 源。
- 不把个人 ROM 仓库写进公开配置。
- 不公开分发包含 `tomiaa12/nesRoms` ROM 数据的 APK。
- App 代码、文档、模拟核心集成代码可以独立维护。
- ROM 数据、本地私有源、个人测试资源放在 git 外部或私有环境中。

## 13. 验收标准

第一版达到以下标准即认为核心闭环成立：

- App 启动后直接进入横屏游戏大厅。
- 至少一个通过私有资源注入准备好的 NES 游戏可以从详情页启动，并使用真实 libretro core 运行。
- FakeEmulatorSession 只能作为阶段性开发替身，不能作为第一版最终验收依据。
- 普通用户不进入设置页也可以完成启动 App、选择游戏、进入详情页、开始游玩、保存进度、退出游戏的完整流程。
- 电视遥控器可以完整浏览大厅、进入游戏详情页、开始游戏、返回大厅。
- 手机触摸可以浏览大厅、进入游戏详情页、开始游戏、操作虚拟按键。
- 手机连接手柄后可以完整操作大厅和游戏。
- 游戏过程中可以暂停、继续、重置、退出。
- SRAM 自动存档可用。
- 1 个自动即时存档槽可用。
- 3 个手动即时存档槽可用。
- 画面比例设置可用。
- 声音设置可用。
- 收藏和最近游玩可用。
- 设置页可调整基础配置，并能看到配置生效。
- 第一版不出现添加游戏源入口。
- 第一版不出现本地 ROM 导入入口。
- 项目不面向公开分发。
