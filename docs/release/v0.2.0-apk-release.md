# Retro Hall v0.2.0 APK Release

## 发布信息

- 版本号：`0.2.0`
- 版本代码：`2`
- Git Tag：`v0.2.0`
- 公开资产：`RetroHall-v0.2.0-release.apk`

## 口径

- Debug APK 用于本地验证。
- Release APK 用于公开下载。
- Release APK 包含 libretro 模拟器核心。
- Release APK 不包含 ROM、私有封面、存档或签名材料。

## 0.2.0 变更

- 详情页将“游戏格式”改为“类型”，展示值跟随 `catalog/index.v2.json` 的 `categories` 类型名（如 FC、SFC、GBA），缺失映射时回退平台名。

## 已验证内容

- `clean assembleRelease`
- release APK 打包 libretro 核心
- 单元测试通过
