# Focus Navigation Spec

## 目标

保证手机手柄、Android TV 遥控器和键盘方向键都能完整操作 App。

## 总原则

- 所有主要交互元素必须可获得焦点。
- 焦点高亮必须明显。
- 焦点移动必须可预测。
- 不允许出现焦点丢失后无法继续操作的页面。
- 触摸不是焦点导航的替代品。

## 大厅焦点

初始焦点：

- 如果存在最近游玩游戏，聚焦最近游玩中的第一个游戏。
- 否则聚焦当前分类下第一个游戏。
- 如果没有游戏，聚焦分类列表的“全部”。

焦点移动：

- 分类区上下移动分类。
- 分类区向右进入游戏网格。
- 游戏网格向左回到分类区。
- 游戏网格内按网格自然方向移动。
- 网格移动到边界时保持当前焦点，不跳到不可见位置。

## 游戏页焦点

手机：

- 虚拟按键可触摸，但不要求每个虚拟按键参与遥控器焦点。
- 菜单按钮必须可获得焦点。

电视：

- 游戏画面本身可以作为焦点容器。
- Back 或 Menu 打开暂停菜单。

## 游戏详情页焦点

初始焦点：

- `开始游戏`

移动规则：

- 上下或左右可在开始游戏、收藏和返回之间移动。
- Confirm 执行当前焦点操作。
- Back 返回进入详情页前的列表和焦点位置。
- Menu 打开设置。

## 暂停菜单焦点

初始焦点：

- `继续游戏`

移动规则：

- 上下移动菜单项。
- Confirm 执行当前项。
- Back 关闭菜单并继续游戏。
- Menu 关闭菜单并继续游戏。

## 设置页焦点

初始焦点：

- 第一个基础设置项。

移动规则：

- 上下移动设置项。
- 左右调整滑杆或选项。
- Confirm 切换开关或进入下一级。
- Back 返回上一页。

## 测试场景

必须手动验证：

- 只用键盘方向键完成大厅浏览、进入详情页和开始游戏。
- 只用遥控器完成大厅浏览、进入详情页和开始游戏。
- 只用手柄完成大厅、游戏、暂停菜单操作。
- 从每个页面按 Back 都能回到预期位置。
