# Hall UI Spec

## 目标

游戏大厅是 App 首屏。用户打开 App 后直接进入横屏大厅，通过焦点、手柄、遥控器或触摸选择游戏。

## 布局

横屏布局：

```text
┌────────────────────────────────────────────┐
│ 顶部：搜索入口                 设置入口     │
├────────────┬───────────────────────────────┤
│ 左侧分类    │ 右侧游戏封面网格                │
│            │                               │
├────────────┴───────────────────────────────┤
│ 底部：A 详情    B 返回    菜单 设置          │
└────────────────────────────────────────────┘
```

## 分类区

必须包含：

- 全部
- 收藏
- 最近游玩
- 至少一个普通分类

分类项必须可获得焦点。当前分类和焦点分类要有清晰区分。

## 游戏网格

每个游戏卡片显示：

- 封面
- 游戏名
- 收藏状态
- 焦点状态

封面缺失时显示占位封面，不显示破图。

## 顶部区

顶部包含：

- 搜索入口
- 设置入口

第一版搜索可以先实现本地标题过滤，不需要复杂搜索建议。

## 底部操作提示

默认显示：

```text
A 详情    B 返回    菜单 设置
```

在键盘环境下可以显示：

```text
Enter 详情    Esc 返回    Menu 设置
```

## 交互

- 方向键左右可在分类区和游戏网格之间移动。
- 方向键上下可在分类区内移动。
- 方向键上下左右可在游戏网格内移动。
- `Confirm` 打开当前焦点游戏的详情页。
- `Back` 从详情页、搜索或设置返回上一层。
- `Menu` 打开设置。
- 触摸点击分类切换分类。
- 触摸点击游戏打开游戏详情页。
- 游戏库、最近游玩、搜索和收藏中的游戏卡片交互保持一致，都先进入游戏详情页，不直接启动游戏。

## 空状态

分类下没有游戏时显示：

```text
没有游戏
```

不要显示技术错误或空白网格。
