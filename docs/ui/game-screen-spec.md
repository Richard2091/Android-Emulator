# Game Screen Spec

## 目标

游戏页承载模拟器画面、虚拟按键、输入分发和暂停菜单入口。

## 手机布局

手机横屏默认显示：

- 全屏游戏画面
- 左下角虚拟方向键
- 右下角 A / B
- 底部中间 Start / Select
- 右上角菜单按钮

虚拟按键必须支持：

- 显示开关
- 透明度
- 大小
- 连接手柄后自动隐藏

## 电视布局

电视横屏默认显示：

- 全屏游戏画面
- 不显示虚拟按键
- 使用遥控器或手柄操作

菜单键或 Back 键打开暂停菜单。

## 游戏画面

真实模拟器接入前显示假模拟器画面：

- 当前游戏名
- 当前模拟器状态
- 最近输入动作

真实模拟器接入后显示 NES 视频帧。

## 输入规则

游戏页消费：

- 方向动作
- `NesA`
- `NesB`
- `Start`
- `Select`
- `Menu`
- `Back`

`Menu` 和 `Back` 打开暂停菜单，不直接退出游戏。

## 暂停菜单

FakeEmulatorSession 阶段暂停菜单包含：

- 继续游戏
- 保存即时存档
- 读取即时存档
- 重置游戏
- 设置
- 退出到大厅

真实 libretro 接入后，保存和读取动作必须调用真实 serialize / unserialize。

## 错误状态

游戏加载失败时显示：

```text
游戏加载失败
```

必须提供返回大厅操作。
