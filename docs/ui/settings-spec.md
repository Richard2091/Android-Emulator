# Settings Spec

## 目标

设置采用双层体验：普通用户默认即可游玩，定制玩家可以主动调整体验。

## 基础设置

必须包含：

- 画面比例
- 滤镜开关
- 声音开关
- 音量
- 虚拟按键显示开关
- 虚拟按键透明度
- 虚拟按键大小
- 虚拟按键位置
- 清理缓存

## 高级设置

必须包含：

- 单个游戏画面比例覆盖
- 单个游戏滤镜覆盖
- 单个游戏声音覆盖
- 手柄连接时自动隐藏虚拟按键
- 自动即时存档开关

## 默认值

- 画面比例：原始比例
- 滤镜：关闭
- 声音：开启
- 音量：100%
- 虚拟按键：手机显示，电视隐藏
- 虚拟按键透明度：55%
- 虚拟按键大小：100%
- 虚拟按键位置：默认横屏布局
- 手柄连接时隐藏虚拟按键：开启
- 自动即时存档：开启

## 交互规则

- 设置项必须可获得焦点。
- 开关用确认键切换。
- 滑杆用左右键调整。
- 返回键返回上一页。
- 设置变更立即写入 DataStore。
- 设置变更尽量立即生效。

## 错误处理

DataStore 写入失败时：

- 显示短提示：`设置保存失败`
- UI 保持在当前页面
- 不让 App 崩溃
