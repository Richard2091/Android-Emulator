# Game Detail Spec

## 目标

游戏详情页是游戏库、最近游玩、搜索和收藏进入游戏前的统一中转页。用户在任意游戏列表中选中游戏后，先进入详情页，再从详情页开始游戏。

## 入口

以下入口都必须进入同一个详情页：

- 游戏库中的游戏卡片
- 最近游玩中的游戏卡片
- 搜索结果中的游戏卡片
- 收藏中的游戏卡片

不同入口进入详情页后，Back 必须回到原入口和原焦点位置。

## 内容

详情页至少显示：

- 游戏封面
- 游戏标题
- 平台
- 分类
- 收藏状态
- 最近游玩时间
- 累计游玩时长

封面缺失时显示占位封面，不显示破图。

## 操作

详情页必须提供：

- 开始游戏
- 收藏 / 取消收藏
- 返回

默认焦点放在“开始游戏”。`Confirm` 执行当前焦点操作。触摸点击“开始游戏”启动游戏。

## 交互

- `Back` 返回进入详情页前的列表。
- `Menu` 打开设置。
- 收藏切换后，收藏页和游戏卡片状态必须同步更新。
- 只有详情页的“开始游戏”会创建游戏会话并进入游戏全屏界面。
