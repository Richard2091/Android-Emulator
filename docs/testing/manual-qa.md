# Manual QA

## 准备

安装 Debug APK 到 Android 手机、Android TV 或模拟器。

如果没有真实 NES core 和 ROM，可以使用 `FakeEmulatorSession` 验证非模拟器流程，但这不算真实 core 路径验收。
手工 QA 只补自动化无法稳定覆盖的屏幕外观、音频听感和遥控器/手柄体验。

## 大厅流程

1. 启动 App。
2. 确认 App 直接进入横屏大厅。
3. 用方向键移动分类焦点。
4. 切换到游戏网格。
5. 用方向键移动游戏焦点。
6. 按 Confirm 进入游戏详情页。

通过标准：

- 焦点移动清楚。
- 不需要触摸也能进入详情页。
- 页面没有空白或崩溃。

## 游戏详情页流程

1. 从游戏库进入任意游戏详情页。
2. 按 Back 返回游戏库，并确认焦点回到原游戏。
3. 从最近、搜索和收藏分别进入游戏详情页。
4. 在详情页切换收藏状态。
5. 在详情页选择开始游戏。

通过标准：

- 所有游戏集合页都先进入详情页，不直接进入游戏页。
- 详情页显示封面、标题、平台、分类、收藏状态、最近游玩时间和累计游玩时长。
- 收藏状态变化能同步到收藏页和游戏卡片。
- 开始游戏后进入游戏页。

## 游戏流程

1. 从详情页开始游戏。
2. 确认进入游戏页。
3. 使用通过私有资源注入准备的真实 NES ROM 和 libretro core。
4. 确认画面持续刷新。
5. 确认音频输出可听，或日志显示音频采样已送达 AudioTrack。
6. 按方向键、A、B、Start、Select。
7. 按 Menu 或 Back。

通过标准：

- 输入能被游戏页接收。
- 真实 NES 游戏可运行。
- Menu 或 Back 打开暂停菜单。
- 游戏页不直接退出。

## 暂停菜单流程

1. 打开暂停菜单。
2. 选择继续游戏。
3. 再次打开暂停菜单。
4. 选择保存即时存档。
5. 选择读取即时存档。
6. 选择重置游戏。
7. 选择退出到大厅。

通过标准：

- 每个菜单项可聚焦。
- 保存和读取有结果提示。
- 退出时返回大厅。

## 设置流程

1. 从大厅进入设置。
2. 修改画面比例。
3. 切换滤镜。
4. 调整音量。
5. 切换虚拟按键显示。
6. 返回大厅。
7. 再次进入设置。

通过标准：

- 设置修改后保存。
- 再次进入设置时值保持。
- 返回键可回到大厅。

## 禁止项检查

确认 App 中没有：

- 本地 ROM 导入入口
- 游戏源入口
- 下载 ROM 入口
- 账号登录入口
- 云同步入口

## Android TV 和手柄流程

1. 在 Android TV 或电视盒子上安装 Debug APK。
2. 只使用遥控器打开 App。
3. 使用遥控器方向键浏览大厅。
4. 使用 OK 进入游戏详情页。
5. 在详情页使用 OK 开始游戏。
6. 使用 Back 或 Menu 打开暂停菜单。
7. 返回大厅。

通过标准：

- 不需要触摸即可完成完整流程。
- 焦点不会丢失。
- 返回路径清晰。

真实手柄流程：

1. 连接蓝牙或 USB 手柄。
2. 使用手柄方向键浏览大厅。
3. 使用手柄 A/B、Start/Select 控制游戏。
4. 断开手柄。

通过标准：

- 手柄输入映射正确。
- 手柄断开不会导致 App 崩溃。

## 后台和恢复流程

1. 游戏运行中按 Home 键进入后台。
2. 等待 5 秒。
3. 重新打开 App。
4. 退出游戏回大厅。

通过标准：

- App 不崩溃。
- 模拟器暂停或恢复行为可解释。
- 退出时尽量保存 SRAM。
